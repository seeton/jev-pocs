# 将棋の対局ログ

先手は人間、後手はJev。2026-09-22の手動試遊2局です。どちらも人間が詰ませて勝ちました。

| 記録 | 指し手数（片側の着手を1手） | 入力 |
|---|---:|---|
| [14:52の対局](shogi-20260922-145214-604000/game.json) | 45 | 盤面・合法手・直近棋譜。戦術補助なし |
| [15:03の対局](shogi-20260922-150334-108038/game.json) | 37 | 王手・詰み・簡易駒交換の戦術情報あり |

後者は [判断ログ](shogi-20260922-150334-108038/decisions.jsonl) も収録しています。
`state` はモデルへの局面情報、`criteria` は全合法手と補助計算、`move` はモデルが選んだUSI指し手です。
`latency_ms` は前処理からAPI応答まで、`preprocessing_ms` はローカルの補助計算の時間です。

各局面の棋譜は `game.json` の `moves` にUSI形式で記録し、`sfen` は最終局面です。
標準初期局面から順に適用すると再現できます。キー・HTTPヘッダーは含みません。
初期版にはモデルIDの記録がなく、欠けている値を後から推定して補ってはいません。
対局条件や人間の指し手を揃えた比較ではなく、棋力改善を立証する結果ではありません。
